# Glowbal Redesign Roadmap

## Goal
Bring the live Glowbal site closer to the premium, cinematic, globally aspirational Canva direction without copying it literally or hurting usability.

## Design translation principles
- Keep the product buildable and clear, not just flashy
- Use the Canva work as mood and direction, not as a pixel-perfect spec
- Make the globe/world motif a signature interaction
- Reduce generic dashboard feel; increase premium guidance feel
- One strong visual hero per page, with calmer supporting sections

## Phase 1 — Visual system foundation
### Outcomes
- Stronger brand consistency across landing + product
- Clear reusable surface/button/type system

### Changes
- Refine core palette: deeper midnight base, cleaner white surfaces, controlled pink/cyan accents
- Tighten typography hierarchy: larger headlines, clearer section spacing, more premium body text rhythm
- Standardize reusable UI primitives:
  - hero sections
  - pills/badges
  - cards/panels
  - inputs and CTA buttons
  - shadows, borders, glow, blur usage
- Audit contrast/readability and reduce visual noise where needed

## Phase 2 — Homepage / brand experience
### Outcomes
- Homepage feels cinematic and distinctive
- Clearer story: explore → match → apply → track

### Changes
- Rebuild hero around a stronger globe focal point and sharper copy
- Improve section sequencing and emotional pacing
- Add stronger feature storytelling panels and stats/proof blocks
- Make CTAs more intentional and product-led
- Ensure mobile still feels premium, not crowded

## Phase 3 — Universities explorer refresh
### Outcomes
- Search feels like the flagship product experience
- Globe filtering becomes the signature interaction

### Changes
- Polish layout around the new left-rail globe
- Upgrade card hierarchy and spacing
- Make filters/results feel more editorial and premium
- Add clearer empty/filter states and stronger country focus feedback
- Keep signed-out CTA visible but more integrated with the new aesthetic

## Phase 4 — Onboarding / guided flow polish
### Outcomes
- Onboarding feels calmer, smarter, and more intentional
- Better alignment with the new visual direction

### Changes
- Simplify visual load per step
- Improve step transitions and spacing
- Rework supporting visuals to feel premium without distracting from the task
- Keep public onboarding flow and auth-gated final save behaviour intact

## Phase 5 — Profile / dashboard / shortlist consistency
### Outcomes
- Product feels like one coherent system after entry

### Changes
- Apply the same surface language and typography to profile/dashboard
- Make My Universities feel more like a premium shortlist / application command center
- Improve consistency of CTA, spacing, and navigation states

## Delivery sequence
1. Visual system refinements and shared primitives
2. Homepage refresh
3. Universities explorer refresh
4. Onboarding polish
5. Profile/dashboard/shortlist consistency pass
6. QA, responsive fixes, performance pass, deploy

## Execution plan started
- Job A: homepage visual refresh toward cinematic Canva-inspired direction
- Job B: universities explorer polish around the globe-led premium experience
- Main session: coordinate, verify, merge, test, and push to main
