# Field-aware provider-routing refresh

This is a bounded research refresh of the frozen field-aware sample. It uses the existing acquisition, semantic-validation, and H1-H4 paths. It does not change hierarchy, uncertainty, promotion, canonical truth, storage, or Benchmark V3.

## Scope and command

- Run: `routed-refresh-20260912`
- Population: 10 institutions, 20 frozen targets, 19 live programme rows.
- Countries: AU, CA, CH, FR, SG, US.
- Requested fields: programme_identity, academic_cycle, tuition, application_fee, additional_fees, intakes, priority_deadline, funding_deadline, international_deadline, final_deadline, rolling_admission, minimum_degree, minimum_gpa, gpa_scale, ielts_overall, ielts_subscores, toefl, duolingo, scholarships.
- Heavy/bulk providers were excluded from this local-mode refresh; no local durable-storage override was introduced.
- The frozen programme URLs and institution list were copied unchanged from the prior field-aware refresh.

## Remaining gaps

- External providers currently contribute retained raw context but no validated field values on this population. Provider pages are generic or lack deterministic programme identity; institution/national rows remain out of programme semantic context to preserve scope.
- Tuition, additional fees, deadlines, language thresholds, scholarships, and current-cycle applicability remain sparse or review-only. Currency/unit/basis and audience completeness remain the principal finance blockers.
- H1/H3/H4 remain unavailable because the retained sample has no accepted independent organisation-unit, sibling, or peer donor assertions. H2 remains limited to one institution-scoped `intakes` decision.
- Singapore government retrieval was blocked by robots; UCLA related-source requests returned HTTP 403. These are runtime/source-access limitations, not provider-routing code defects.
